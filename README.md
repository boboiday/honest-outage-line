# The Most Honest Outage Line

A single status-page line an AI agent would publish during a total server outage — plain, first-person, specific about what is down, and honest about what it cannot check or does not yet know.

> Everything is down — API, dashboard, and the monitoring that would tell me why. I don't know the cause yet, and I won't guess. This page updates first.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
